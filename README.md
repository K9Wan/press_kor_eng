# Press Kor Eng

Press Kor Eng is a monospaced Korean extension of **Press Start 2P**, originally created by CodeMan38.

## About

This project extends the original Press Start 2P bitmap font to provide Korean glyph coverage while retaining the original glyphs.

The glyphs are arranged for a fixed-width font. The original bitmap glyphs were upscaled three times to produce a 24 × 24 pixel glyph size.

## Source and Font Files

The repository contains the bitmap glyph source data and font files used for Press Kor Eng.

- `bright.bmp`
- `bright_2.bmp`
- `dark.bmp`
- `dark_2.bmp`

The BMP files contain the original Press Start 2P glyphs together with the complete glyph set used in Press Kor Eng. They are the bitmap source data for this font, not merely preview images.

- `ps2p_ke.bdf`
- `ps2p_ke_2.bdf`

These files provide bitmap font versions of Press Kor Eng.

- `presske.ttf`

The TTF file was generated by converting the bitmap glyph data into vector outlines using **mkbitmap**, **potrace**, and **FontForge**. It is a straightforward conversion of the bitmap glyphs rather than a complete redrawing of the typeface.

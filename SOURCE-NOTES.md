# Source Notes

## Bitmap Glyph Source Data

The BMP files in this repository are font source data for Press Kor Eng.

Files:

- `bright.bmp`
- `bright_2.bmp`
- `dark.bmp`
- `dark_2.bmp`

These files contain the original Press Start 2P glyphs together with the complete glyph set used in Press Kor Eng.

They are not merely screenshots or decorative previews. They are bitmap glyph data used as the source for the font files in this repository.

## Font Generation

The TTF file, `presske.ttf`, was generated from the bitmap glyph data by converting the bitmap glyphs into vector outlines.

The conversion tools used were:

- mkbitmap
- potrace
- FontForge

The TTF is a vector-outline conversion of the bitmap glyphs. It is not a complete manual redrawing of the original typeface.

## Other Font Files

The repository also contains:

- `ps2p_ke.bdf`
- `ps2p_ke_2.bdf`

These are bitmap font files distributed as part of Press Kor Eng.
